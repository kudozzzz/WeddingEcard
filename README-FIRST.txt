HOW TO USE THIS
---------------
1. Create an empty project folder on your laptop, e.g.  ~/wedding-invite
2. Copy CLAUDE.md, public/ and reference/ into it.
3. Drop your MP3 in as public/audio/theme.mp3 (compress it first — command is in
   CLAUDE.md section 6). It is NOT included in this bundle.
4. cd ~/wedding-invite && claude
5. First message to Claude Code:

   "Read CLAUDE.md fully, then do step 1 of the build order in section 10.
    Scaffold the Vite project, wire up the design tokens and fonts, and stub all
    eight sections with the real copy and real images from public/. No animation
    yet. Then tell me how to run it on my phone."

   Work through section 10 one step at a time. Do not ask it to build everything
   at once.
